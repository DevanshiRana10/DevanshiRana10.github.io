# Devanshi Rana - Portfolio

A professional, modern, and lightweight personal portfolio website for a Python Backend Developer and Odoo Developer. Built entirely with HTML, CSS, and vanilla JavaScript.

## Features
- **Fully Responsive**: Adapts seamlessly from 320px mobile screens to large desktop monitors.
- **Dark Theme by Default**: Modern, sleek aesthetics targeted towards developer roles.
- **Performance Optimized**: Zero heavy frontend frameworks. No unnecessary dependencies. Fast loading.
- **SEO Ready**: Proper semantic HTML, Open Graph tags, and meta descriptions included.
- **Accessible**: Keyboard navigation support and respect for user's reduced-motion preferences.

## Project Structure
```text
.
├── index.html        # Main HTML layout and content
├── css/
│   └── style.css     # Dark theme styles, responsive layout, animations
├── js/
│   └── script.js     # Interactivity: Mobile menu, Scroll reveal, Sticky nav
├── assets/
│   └── resume/       # Place your resume PDF here
└── README.md
```

## Running Locally

To run the project locally without any CORS or file protocol issues, start a simple HTTP server:

```bash
# Using Python 3
python3 -m http.server 8000
```

Then, open `http://localhost:8000/` in your web browser.

## Deployment

This website is designed to be easily deployed to **GitHub Pages**.

1. Commit your changes.
2. Push to the `main` branch of `DevanshiRana10.github.io`.
3. GitHub Pages will automatically serve the content at `https://devanshirana10.github.io/`.
